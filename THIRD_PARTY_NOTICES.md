# Third-party materials

Arc uses the official [Muse Gadget SDK](https://github.com/facebookincubator/muse-gadget-sdk), primarily Apache-2.0 with upstream exceptions described in its README/LICENSE files, and [ESP-IDF](https://github.com/espressif/esp-idf), which includes components under their respective licenses.

The resolved Waveshare BSP is `waveshare/esp32_s3_touch_amoled_1_75c` 3.0.0. Other exact dependency versions and hashes are in `configs/dependencies.lock`. The lock file is build metadata preserved from the upstream component manager. No vendor firmware binary, SDK signing key, avatar asset or full upstream source tree is redistributed in Git.

The repository's scripts and guides were assembled for the owner during this Arc project. Public visibility of this repository does not change the licenses or grant new rights over upstream code, the vendor factory image, or Muse's avatar.
